# Task 1 — MNIST Dataset Digit Recognition

## Objective

The objective of this task is to:

1. Download the MNIST dataset
2. Load image data
3. Train an Artificial Intelligence model
4. Classify handwritten digits from 0–9

This task demonstrates basic Machine Learning and Neural Network concepts.

## Technologies Used

- Python 3.14.3
- PyTorch
- Torchvision
- Matplotlib
- NumPy

## Dataset Used

MNIST Dataset

The dataset contains:

- 60,000 training images
- 10,000 testing images
- Handwritten digits from 0–9

Image size:

- 28 × 28 pixels
